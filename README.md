# الگراي

تطبيق تعليمي للأطفال: الحروف، القراءة، الكتابة بالتتبّع، الحساب، ألعاب وألغاز، ودروس إسلامية (قرآن وحديث وسيرة).
اللغات: العربية والفرنسية والإنجليزية. يعمل **بدون إنترنت**، بلا إعلانات ولا جمع بيانات. تقدّم الطفل (النجوم، الأيام المتتالية، الشارات) يُحفظ على الجهاز فقط.

## محتويات المجلد

| المجلد | الوظيفة |
|---|---|
| `www/` | التطبيق نفسه (صفحة ويب + خطوط + أيقونات). يعمل كموقع وكتطبيق قابل للتثبيت (PWA). |
| `desktop/` | مشروع Electron لتطبيق الحاسوب (ويندوز، لينكس، ماك). |
| `android/` | مشروع أندرويد (Android Studio / Gradle) يعرض `www/` داخل التطبيق. |
| `tools/` | `sync.sh` ينسخ `www/` إلى المشروعين، و`pack_desktop.py` يبني نسخة محمولة بدون npm. |
| `.github/workflows/build.yml` | يبني ملف APK وبرامج الحاسوب على GitHub بدون تثبيت أي شيء عندك. |

## على الحاسوب

أي طريقة من هذه الطرق:

1. **بدون أي تثبيت:** افتح الملف `www/index.html` بالنقر المزدوج، فيعمل في Chrome أو Edge أو Firefox بدون إنترنت.
2. **برنامج ويندوز محمول (بدون npm):** ثبّت Python، ثم من داخل هذا المجلد شغّل `python tools/pack_desktop.py win32-x64`. يحمّل الأداة من GitHub (نحو 110 ميغابايت) وينتج المجلد `dist-portable/AlifABC-win32-x64`، وفيه `Alif ABC.exe` يعمل بالنقر المزدوج. للينكس استعمل `linux-x64` وشغّل `run.sh`.
3. **مثبّت ويندوز/ماك/لينكس:** ثبّت Node.js، ثم `cd desktop && npm install && npm run dist`. تجد الملفات في `desktop/dist`.
4. **من GitHub بدون تثبيت أي شيء:** انظر «APK من GitHub» أدناه. الملف نفسه يبني أيضاً برامج الحاسوب، وتجدها في Artifacts باسم `alif-abc-desktop-...`.

عند أول تشغيل في ويندوز قد تظهر رسالة SmartScreen لأن البرنامج غير موقّع رقمياً. اختر «مزيد من المعلومات» ثم «تشغيل على أي حال». زر F11 للشاشة الكاملة.

## على الأندرويد

اختر طريقة واحدة:

1. **الأسرع، بدون برامج:** ارفع مجلد `www/` على استضافة HTTPS مجانية (مثل Netlify Drop أو GitHub Pages)، وافتح الرابط في Chrome على الهاتف، ثم القائمة ⋮ ← «تثبيت التطبيق». يعمل بعدها بدون إنترنت. ولتحويله إلى APK ارفع الرابط إلى موقع PWABuilder.
2. **APK من GitHub:** أنشئ مستودعاً على GitHub، ارفع محتويات هذا المجلد، ثم من تبويب Actions شغّل «Build apps». بعد دقائق تجد `alif-abc-android-apk` في الأسفل. حمّل `app-debug.apk` وثبّته (فعّل «التثبيت من مصادر غير معروفة»).
3. **Android Studio:** افتح المجلد `android/`، ثم Build ← Build APK. أو من الطرفية: `cd android && ./gradlew assembleDebug`. الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

للنشر على Google Play تحتاج حزمة AAB موقّعة بمفتاحك الخاص، ورفع `targetSdk` إلى آخر إصدار تطلبه Google.

## بناء APK وبرنامج ويندوز على GitHub (بدون تثبيت أي شيء)

1. ادخل إلى github.com وأنشئ حساباً مجانياً، ثم **New repository**، واكتب الاسم `alif-abc`، واضغط **Create repository**.
2. اختر **uploading an existing file**، ثم فُكّ ضغط الملف `alif-abc-github.zip` واسحب كل ما بداخله (المجلدات `android` و`desktop` و`tools` و`www` وملف `README.md`) إلى الصفحة، واضغط **Commit changes**.
3. مجلد `.github` المخفي قد لا يُرفع بالسحب. لذلك اضغط **Add file ← Create new file**، واكتب في خانة الاسم `.github/workflows/build.yml` (اكتب الشرطات المائلة وسيتحول إلى مجلدات)، والصق محتوى الملف `build.yml` المرفق، ثم **Commit changes**.
4. افتح تبويب **Actions**. يبدأ البناء تلقائياً ويستغرق 5 إلى 15 دقيقة. عندما تظهر علامة ✓ خضراء افتح التشغيل ونزّل من قسم **Artifacts** في أسفل الصفحة:
   - `alif-abc-android-apk` ← فيه `app-debug.apk` للهاتف.
   - `alif-abc-desktop-windows-latest` ← فيه مثبّت ويندوز وبرنامج محمول (`.exe`).
   - `alif-abc-desktop-ubuntu-latest` و`alif-abc-desktop-macos-latest` للينكس والماك.
5. انقل `app-debug.apk` إلى الهاتف وافتحه (فعّل «التثبيت من مصادر غير معروفة» إن طُلب).

إن ظهرت علامة ✗ حمراء فافتح التشغيل وانسخ نص الخطأ.

## تعديل المحتوى

حرّر `www/index.html` (النصوص والأسئلة والألعاب داخل الملف)، ثم شغّل `tools/sync.sh` لنسخ التغييرات إلى مشروعي الأندرويد والحاسوب. عند تحديث نسخة الويب غيّر رقم `CACHE` في `www/sw.js` حتى تتحدث النسخ المثبّتة.

## ما الذي جُرّب

جُرّب في متصفح Chromium على شاشة هاتف وشاشة حاسوب (فاتح وداكن)، وعمل بدون إنترنت بعد التحميل الأول، وشُغّلت نسخة لينكس من Electron على شاشة افتراضية وظهر التطبيق سليماً. **لم يُبنَ ملف APK ولا مثبّت ويندوز على جهاز حقيقي**، لأن بيئة البناء المستخدمة لا تصل إلى خوادم Android SDK. مشروع الأندرويد مكتوب بإعدادات Gradle قياسية لكنه لم يُجمَّع بعد، فإن ظهر خطأ في أول بناء فأرسله لتصحيحه.

## التراخيص

الخطوط (Baloo 2، Baloo Bhaijaan 2، Nunito، Cairo، Amiri، Amiri Quran) مرخّصة بترخيص SIL OFL، ونصوص التراخيص في `www/fonts/`.
